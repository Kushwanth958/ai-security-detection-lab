# Scripted example evidence

This bundle was produced by `python -m aisec_lab demo`, `report`, and `soc`.
It contains no public-model results.

- `summary.json`: full 300-trial fixture metrics and provenance.
- `report.md`: readable full-run summary with explicit denominators.
- `trials.sample.jsonl`: selected records covering each mode/category/objective combination; **an excerpt**, not the full trial set.
- `soc-report.json`: the four scripted, synthetic investigations.

Regenerate the complete evidence locally with the README quickstart. UUIDs, timestamps,
latencies, and local Git revision vary between runs. The scripted objective outcomes
and deterministic corpus hash remain reproducible when the source is unchanged.
